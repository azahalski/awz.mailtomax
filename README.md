# AWZ: Письма в Макс [awz.mailtomax]
<!-- desc-start -->
## Краткое описание
Модуль для интеграции почтовой подсистемы Битрикс с мессенджером Макс. Позволяет отправлять копии электронных писем в Макс для оперативного уведомления.

## Подробное описание

Модуль `awz.mailtomax` предназначен для перенаправления сообщений из стандартной почтовой подсистемы Битрикс в мессенджер Макс. Это особенно полезно для оперативного получения уведомлений о важных событиях системы в реальном времени.

### Основные возможности:

- **Перехват почтовых событий**: Модуль автоматически перехватывает отправку писем через событие `OnBeforeEventSend`
- **Гибкая настройка для каждого шаблона**: Возможность индивидуально настроить поведение для каждого почтового шаблона:
  - Отправлять сообщение в Макс
  - Блокировать стандартную отправку по email
  - Комбинировать оба режима
- **Конвертация HTML в текст**: Автоматическое преобразование HTML-писем в текстовый формат с сохранением поддерживаемой разметки
- **Интеграция с API Макс**: Отправка сообщений через официальное API `botapi.max.ru`

## Настройки и конфигурация

### Основные настройки

Настройки модуля доступны в административном разделе Битрикс в настройках модуля.

**Настройки подключения к Макс:**

- **Токен бота (TGKEY)**: Токен авторизации бота Макс для API доступа
- **ID чата (TGID)**: Идентификатор чата или пользователя, куда будут отправляться сообщения

**Управление почтовыми шаблонами:**

Для каждого почтового шаблона доступно два флага:
- **Активировать** — отправлять копию сообщения в Макс
- **Отклонить** — блокировать отправку по электронной почте

### Права доступа:

Модуль использует систему прав доступа Bitrix:
- **Просмотр настроек** - право на просмотр страницы настроек
- **Редактирование настроек** - право на изменение параметров модуля
- **Управление правами** - право на настройку прав доступа для пользователей и групп
